
# 🇮🇳 UPI Transaction Analysis Dashboard | Advanced Excel

An interactive **UPI Transaction Analysis Dashboard** built entirely in Microsoft Excel to analyze approximately **500,000 UPI transactions across India**. This project uses PivotTables, PivotCharts, interactive slicers, advanced Excel formulas, and professional dashboard formatting to analyze transaction trends, banking performance, payment methods, and potential fraud indicators.

## 📊 Project Overview

The dashboard provides a consolidated view of UPI transaction activity, including transaction volumes, total transaction amounts, cashback, success rates, suspected fraud, and risk scores.

Built using Advanced Excel, this project demonstrates practical skills in data analysis, business intelligence, KPI development, data visualization, and interactive dashboard creation.

## 🎯 Business Objectives

- Analyze transaction volume and total transaction value across UPI applications.
- Monitor transaction success rates and transaction statuses.
- Compare transaction amounts across banks, Indian states, and transaction types.
- Identify peak transaction hours and daily transaction trends.
- Evaluate average risk scores across merchant categories.
- Analyze suspected fraudulent transactions.
- Develop an interactive dashboard for business reporting and decision-making.

## 📈 Dashboard Visualizations

### 1. Daily Transaction Trend
Analyzes daily transaction amounts to identify fluctuations and transaction patterns.

### 2. Transactions by UPI Application
Compares transaction distribution across PhonePe, Google Pay, Paytm, Amazon Pay, BHIM, and other supported applications.

### 3. Transactions by Status
Analyzes successful, failed, pending, and refunded transactions.

### 4. State-wise Transaction Analysis
Visualizes transaction amounts across Indian states.

### 5. Bank-wise Transaction Analysis
Compares transaction amounts across participating banks.

### 6. Transaction Type Analysis
Analyzes transaction values by:
- P2M
- P2P
- Bill Payment
- Online Shopping
- Recharge
- Subscription
- Wallet Transfer

### 7. Hourly Transaction Analysis
Identifies high-activity hours and daily transaction patterns.

### 8. Average Risk Score by Merchant Category
Compares average risk scores across categories such as credit card bills, utilities, education, shopping, travel, and food and dining.
